# Intended Use

## Purpose

This document describes the intended use of the Two Sum project and the audience for its design, testing, and deployment.

## Intended Audience

- Students learning algorithm implementation and analysis.
- Developers practicing C++ software engineering.
- Reviewers validating test coverage, CI, and documentation completeness.

## Scope

The project covers:
- Two different Two Sum implementations in C++.
- Automated unit testing for functional and edge cases.
- CI pipeline using GitHub Actions.
- Docker support for containerized build and test execution.

## Use Cases

- Validate pair selection logic for a target sum.
- Compare brute-force and hash-table implementations.
- Demonstrate a reproducible C++ build and test workflow.
